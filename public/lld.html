1. Executive Summary & Problem-Solution

In urban Ethiopia, finding a residential or commercial rental property has historically been monopolized by informal middlemen (delalas). This has resulted in systemic pain points:

  • Unregulated Broker Fees: Demands of up to one month's rent from both landlord and tenant.
  • Advance Viewing Scams: Fraudsters asking for prepaid mobile money before viewing properties that do not exist.
  • Unverified & Stolen Listings: Fake photos copied across multiple platforms without owner knowledge.

EthioServe Rent solves this through direct landlord-tenant communication, mandatory government ID verification (Kebele / Fayda National ID / Passport), transparent ETB pricing, and Telebirr/CBE featured monetization.

5. Database Relational Schema (PostgreSQL)

-- Core Tables Summary
CREATE TABLE users (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    first_name VARCHAR(60) NOT NULL,
    last_name VARCHAR(60) NOT NULL,
    email VARCHAR(120) UNIQUE NOT NULL,
    phone VARCHAR(20) UNIQUE NOT NULL,
    password_hash VARCHAR(255) NOT NULL,
    role VARCHAR(20) CHECK (role IN ('tenant', 'landlord', 'admin')),
    status VARCHAR(20) CHECK (status IN ('active', 'suspended')),
    is_verified_landlord BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

CREATE TABLE properties (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    owner_id UUID NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    title VARCHAR(200) NOT NULL,
    rent_price NUMERIC(12, 2) NOT NULL, -- Ethiopian Birr (ETB)
    property_type VARCHAR(40) NOT NULL,
    bedrooms INT NOT NULL DEFAULT 1,
    bathrooms INT NOT NULL DEFAULT 1,
    city VARCHAR(60) NOT NULL,
    sub_city VARCHAR(60) NOT NULL,
    status VARCHAR(20) DEFAULT 'available',
    featured_tier VARCHAR(20) DEFAULT 'basic', -- basic, premium (300 ETB), gold (800 ETB)
    is_verified BOOLEAN DEFAULT FALSE,
    amenities JSONB DEFAULT '[]'::jsonb,
    images JSONB DEFAULT '[]'::jsonb
);

CREATE TABLE conversations (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    tenant_id UUID NOT NULL REFERENCES users(id),
    landlord_id UUID NOT NULL REFERENCES users(id),
    property_id UUID NOT NULL REFERENCES properties(id),
    last_message TEXT,
    last_message_time TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);

9. Fraud Detection & Safety Engine

The platform incorporates algorithms to protect both tenants and landlords:

  • Duplicate Photo Fingerprinting: Image hashes prevent rogue brokers from scraping photos and re-posting at inflated rates.
  • Price Anomaly Heuristics: Flags properties listed at < 35% of sub-city median (common advance-inspection-fee bait scam).
  • Direct Landlord Anti-Broker Guarantee: In-app reminders that viewing inspections are 100% free with direct owners.
